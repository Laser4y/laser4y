# Laser4y Premium

Cria um site profissional para a marca Laser4y - Corte/Gravação Premium.
Produtos e serviços: Corte/gravação Laser , Sublimação , Impressão 3D. 
Estrutura:
1 - Homepage (Página inicial)
2 - Página “Sobre”
3 - Produtos / Serviços
4 - Contactos
5 - Provas sociais (testemunhos / reviews)
7 - Equipa
8 - Formulário de registo
Design: Minimalista, criativo, disruptivo que responda ao branding da marca( logo em anexo)
